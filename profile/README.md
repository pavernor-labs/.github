# Pavernor Labs

We build the measurement layer for agents. An agent you cannot evaluate is an
agent you cannot trust — so we treat the evaluation oracle as the product, not
an afterthought.

## How we work

- **Fix the oracle before the agent.** A passing test that cannot fail is worse
  than a failing one.
- **No invented numbers.** If it was not measured, it is not claimed.
- **Small surface, sharp edges.** One workflow done properly beats ten demos.
